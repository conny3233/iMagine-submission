# 시연 촬영 순서

두 앱을 찍을 때 **어디를 어떤 순서로 누르는지** 적어 둔 문서입니다. 여기 적힌 답을 그대로 고르면
이미 블록체인에 기록해 둔 영수증과 **같은 길**이 되어, 마지막 대조 장면에서 "일치"가 나옵니다.

- 앱 ① iM Docent: <https://i-magine-yzla.vercel.app/consent.html>
- 앱 ② iMprint: <https://i-magine-yzla.vercel.app/vault.html>
- 제출본(인터넷 없이): `web/dist-offline/consent.html` · `vault.html` — 더블클릭

> 촬영 전에 `cd web && npm run e2e -- --url https://i-magine-yzla.vercel.app --record` 를 한 번 돌려 22항목이 모두 ✔ 인지 확인하세요 (Sepolia 에 영수증 3건을 실제로 적습니다).
> iMprint 보관함에는 **같은 약관마다 가장 최근 결정 하나만** 남습니다. 촬영 전 연습으로 쌓인 영수증은 새로 동의하면 저절로 바뀝니다.
> 화면에 보이는 숫자(금리 비교)는 **팀이 정한 가상 예시**입니다. 실제 판매 금리라고 말하지 마세요.

## 장면 1 — 대출 약관 이해하고 동의하기 (약 2분)

`consent.html?product=ssdam-loan` 으로 열면 대출 약관이 바로 열립니다.

| 순서 | 누르는 곳 | 화면에서 보여 줄 것 |
|---|---|---|
| 1 | 메인 "상품 가입" | 상품 2개(ISA·대출)와 [필수] 약관 줄 |
| 2 | **대출 약관·설명서** 줄 | 원문 14쪽이 그대로 뜬다 (약관 4쪽 + 상품설명서 10쪽) |
| 3 | **핵심조항 확인하기** | 고객에게 결과가 돌아오는 9개 조항만 빨갛게 바뀐다 |
| 4 | 글자 크기 슬라이더 | 원문이 커진다 (큰 글씨 선택은 영수증에도 남는다) |
| 5 | 오른쪽 위 **hard → easy** | 같은 조항이 쉬운 말 카드 9장으로 바뀐다 |
| 6 | "기준금리가 바뀌면" 카드 | **금리 비교** — +1%p 면 1년에 30만 원 더 낸다. +0%p 도 눌러 차이 0을 보여 준다 |
| 7 | 아래 **돋보기** | AI 요약이 뜬다. (자주 묻는 질문은 원고 대기 중) |
| 8 | **동의** | 확인 문제 1/4 시작 |
| 9 | 문제 4개 | **기록된 영수증과 같은 길**: ① A → ② **C(일부러 오답)** → 다른 문제로 → **A** → ③ B → ④ C |
| 10 | **확인 마치기 → 동의함** | 틀린 개수("5문제 중 1문제를 틀렸어요")와 "맞힌 개수와 상관없이 동의 여부는 직접 골라 주세요" 문구를 보여 준다 |
| 11 | 완료 화면 | 약관·결정·읽은 방식·확인 문제·금리 비교·영수증 번호·지문. "블록체인에 적는 중" → 10~30초 뒤 **"✓ 블록체인에 적었어요 · 블록 N"** |
| 12 | **iMprint에서 보기** | 방금 받은 영수증이 iMprint 에 담겨 열린다 → 장면 3 으로 |

> 완료 화면의 영수증은 **그 자리에서 새로 만든 영수증**(번호 `rcpt_app_…`)이고, 기록 서버가 **바로 Sepolia에 적습니다**.
> "적었어요"는 체인에서 블록을 확인한 뒤에만 뜹니다. 그 전에 "방금 올라갔다"고 말하지 마세요.
> 기록이 늦으면(테스트넷 혼잡) 완료 화면에서 잠시 기다리세요. 실패하면 [다시 적기]가 나옵니다. iMprint 로 먼저 넘어가도 거기서 기록 확인을 이어 갑니다.
> 거부해도 영수증이 같은 방식으로 기록됩니다.
> 촬영 전: `https://i-magine-yzla.vercel.app/api/record` 가 `"ready":true` 인지 확인하세요.

## 장면 2 — 틀렸을 때 (약 40초)

> ⚠️ 이 장면은 **동의하지 않기**로 끝납니다. 같은 약관은 최근 결정 하나만 보관함에 남으므로, 장면 1 **보다 먼저** 찍거나
> 다른 상품(ISA)으로 찍으세요. 장면 1 뒤에 대출로 찍으면 장면 3 의 보관함에 거부 영수증이 뜹니다.

| 순서 | 누르는 곳 | 보여 줄 것 |
|---|---|---|
| 1 | 아무 문제나 **틀린 답** → 정답 확인 | "이 부분을 다시 볼게요" + 그 조항 카드만 다시 설명 |
| 2 | **다른 문제로 다시 확인** | 같은 조항의 **다른 문제**가 나온다. AI가 만든 문제면 "AI가 만든 문제" 표시가 붙는다 |
| 3 | 또 틀린다 | 멈추지 않고 **원문에서 다시 읽기 / 처음부터 / 동의하지 않기** 3가지를 준다 |
| 4 | **동의하지 않기** | 거부도 영수증이 나온다 — 거부는 실패가 아니라 정상적인 선택 |

## 장면 3 — iMprint 에서 대조하기 (약 1분 30초)

| 순서 | 누르는 곳 | 보여 줄 것 |
|---|---|---|
| 1 | 장면 1의 **iMprint에서 보기** (또는 vault.html) | 보관함에 방금 받은 대출 영수증 (다른 약관에 동의한 적이 있으면 그 영수증도 한 줄씩) |
| 2 | 방금 받은 **은행여신거래기본약관(가계용) · 가계대출 상품설명서** | 종이 영수증 모양 — 확인한 조항, 1차 오답 → 2차 정답, 계산 결과, 결정 |

| 5 | **공개 장부에서 직접 확인하기** | Etherscan 이 열린다 — 방금 기록한 거래 (미리 기록한 대출 영수증은 [이 거래](https://sepolia.etherscan.io/tx/0xd67f7204b2e10e061d22c49d0da62624dc24555ca7367279fe0e519e2162dca0), 블록 11725548) |

## 장면 4 — 바꾸면 들킨다 (선택, 약 30초)

영수증 파일을 복사해 내용을 한 글자 바꾸고 다시 해시를 계산해 보여 줍니다.

```powershell
node -e "import('./scripts/lib/canonical.mjs').then(async c => {
  const fs = await import('node:fs');
  const f = JSON.parse(fs.readFileSync('data/receipts/rcpt_loan_0002.json','utf8'));
  const t = structuredClone(f.payload); t.decision.choice = 'decline';
  console.log('체인에 적힌 지문 :', f.recordHash);
  console.log('원본 다시 계산   :', await c.recordHash(f.payload));
  console.log('동의→거부로 바꾼 뒤:', await c.recordHash(t));
})"
```

원본은 같은 값, 바꾼 것은 완전히 다른 값이 나옵니다.

## 말할 때 주의할 것

- 금리·원금 숫자는 **가상 예시**입니다. iM뱅크가 실제로 파는 조건이 아닙니다.
- 이 앱은 동의를 **받아 주는** 서비스가 아니라, 무엇을 보고 동의했는지 **남기는** 서비스입니다.
- 해시는 "내용이 그대로인지" 만 증명합니다. 설명이 법적으로 정확하다거나 본인확인을 했다는 뜻이 아닙니다.
- 문제를 두 번 틀렸다고 "법적으로 동의할 수 없다"고 말하지 마세요. 시제품의 학습 진행 규칙입니다.
- 쉬운 설명·요약·확인 문제는 **AI 초안**이고 사람 검수가 끝나지 않았습니다. 영상에서 "검수 완료"라고 말하지 마세요.
- 대출 약관·상품설명서는 가계대출 **공통 서류**입니다. 쓰담쓰담 전용 문서가 아닙니다.
